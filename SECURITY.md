# Security reporting

Use [GitHub's private vulnerability reporting form](https://github.com/avalonreset/legends-dataforseo-kit/security/advisories/new)
for credential disclosure, authorization bypasses, unsafe HTTP behavior, or
other suspected vulnerabilities. Do not report credentials or exploit details
in a public issue.

Include the affected package version, a minimal sanitized reproduction, expected
and actual behavior, and the potential impact. Never include a real password,
Authorization header, customer query, or raw account response. If a credential
has already leaked, rotate it with the provider before sharing a reproduction.

Security fixes target the latest published version. Older immutable versions
remain available for reproducibility but are not separate maintenance branches.
Reports are handled on a best-effort basis; no response-time guarantee is made.

For ordinary bugs, use the [issue forms](https://github.com/avalonreset/legends-dataforseo-kit/issues/new/choose).
